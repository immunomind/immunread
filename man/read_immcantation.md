

# Read Immcantation AIRR-like tables

[**Source code**](https://github.com/immunomind/immunread/tree/main/R/read_immcantation.R#L15)

## Description

Reads Immcantation AIRR-like tables in bulk or single-cell mode and maps
their receptor and abundance fields to AIRR-style columns.

Supplied secondary chains are retained in single-cell mode;
<code>immundata</code> ranks chains when constructing receptors.

## Usage

<pre><code class='language-R'>read_immcantation(
  path,
  schema,
  manifest = NULL,
  manifest_file_col = "file",
  column_profile = "standard",
  repertoire_schema = "&lt;auto&gt;",
  mode = c("sc", "bulk"),
  ...
)
</code></pre>

## Examples

``` r
library("immunread")

path <- system.file("extdata", "immcantation", "4.6.0", "contigs.csv.gz",
  package = "immunread", mustWork = TRUE)
idata <- read_immcantation(path, schema = c("v_call", "junction_aa"),
  mode = "sc", output_folder = tempfile("immunread-"))
```
